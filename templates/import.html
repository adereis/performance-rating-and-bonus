Supported File Formats
Bonus Data Files (Required Columns)
  • Associate + Associate ID — Employee name and unique identifier
  • Direct Manager or Supervisory Organization — Team/manager info
  • Job Title or Current Job Profile — Role name
  • Annual Bonus Target % — Target bonus as % of salary
  • Bonus Target (Local) or Bonus Target - Local Currency — Target amount
Bonus Data Files (Optional Columns)
  • Base Pay All Countries (Local) — Base salary
  • Management Level — For detecting managers
  • Country, Hire Date, Grade
  • Proposed % of Target Bonus — Prior allocation (historical imports)
  • Notes — Justification text (historical imports)
Talent Calibration Files
  • Worker + Associate ID — Employee name and identifier
  • Performance: What / Performance: How — Assessment ratings
  • Overall Performance Rating — Derived overall (High Impact, Successful, etc.)
  • Future Talent: Growth Agility / Future Talent: Change Agility
  • Identified as Future Talent? — Future talent flag
  • Movement Readiness — Readiness for role change
  • Proposed Talent Actions — Development plans
  • Management Level — For manager detection
Files are auto-detected based on their columns. Both old (pre-2025) and new (2025+) Workday export formats are supported. Employee matching uses Associate ID.
