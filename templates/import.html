Supported File Formats
Bonus Data Files
  • Associate — Employee full name
  • Associate ID — Unique employee identifier
  • Supervisory Organization — Team/org name (manager name in parentheses)
  • Current Job Profile — Job title
  • Currency or currency in header like (AUD)
  • Annual Bonus Target Percent — Target bonus as % of salary
  • Bonus Target - Local Currency — Target bonus amount
Talent Calibration Files
  • Performance: What / Performance: How — Assessment ratings
  • Future Talent: Growth Agility / Change Agility
  • Movement Readiness — Readiness for role change
  • Management Level — Used for manager detection
Files are auto-detected based on their columns. Both file types must include Associate ID for employee matching.
